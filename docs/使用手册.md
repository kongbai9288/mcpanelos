# 使用手册（Linux 小白版）

## 第 0 步：认识几个概念

- **实例**：一个 MC 服务端（一个世界）。可以同时有多个，互不干扰。
- **目录**：世界和插件都在 `/srv/minecraft/<实例名>/` 里。
- **面板**：一个网页，浏览器打开就能点，不用记命令。
- **提权**：改防火墙、装 Java 这类操作需要 root 权限，面板会自动处理（见第 4 步）。

## 第 1 步：装好并打开面板

```bash
sudo bash install.sh          # 装完会自动启动面板服务
systemctl status mcpanel      # 看它是否活着
hostname -I                   # 看这台机器的 IP，比如 192.168.1.23
```

浏览器打开 `http://192.168.1.23:8850/`。手机连同一个 Wi-Fi 也能开。

## 第 2 步：开第一个服

两种方式任选：

**A. 网页**：「服务器」页 → 填实例名 → 选类型（推荐 Paper）→ 版本留空自动取最新 → 内存 2G → 端口 25565 → 勾选同意 EULA → 创建。

**B. 命令行向导**：`mcpanel wizard`，一路回车即可。

创建后点「启动」，在「控制台」页看到 `Done (...)` 就是好了。

## 第 3 步：让朋友连进来

1. 「防火墙」页 → 点「放行 Java 25565」（基岩版点 19132/UDP）
2. 「联机/映射」页 → 看「连接地址」表
   - 同一个 Wi-Fi：直接把「局域网地址」发给朋友
   - 不在同一个网络：点「安装 Tailscale」→ 按提示登录 → 用「虚拟网」那列地址
   - 有公网 IP：点「UPnP 自动映射」，用公网地址

## 第 4 步：配置自动提权（很重要）

面板里改防火墙、装 Java 需要 root。三种方式，从优到次：

1. 直接用 root 跑面板（install.sh 默认就是）
2. **写入免密 sudoers**：`mcpanel sudo` → 选 1，只放行 systemctl/ufw/apt 等必需命令
3. 保存密码：面板「设置」页填 sudo 密码，加密存在本地（`/var/lib/mcpanel/secret.enc`，权限 600）

## 第 5 步：开机自启

「自启动」页 → 点「安装自启」。之后机器重启 MC 会自动起来。
想让面板自己也是开机启动：`mcpanel service`。

## 第 6 步：日常维护

- 「清理」页：先「扫描」，勾选后「清理选中」。建议开「每日维护」流水线自动做。
- 「日志分析」页：出问题先看这里，它会告诉你是插件冲突、内存不够还是区块损坏。
- 「流水线」页：写 YAML 或简单命令脚本，一键跑备份/清理/重启。

### 流水线示例

```yaml
name: 每日维护
env:
  SERVER: survival
steps:
  - name: 备份世界
    action: backup
    target: ${SERVER}
  - name: 清理旧日志
    run: find ${SERVER}/logs -name "*.log.gz" -mtime +7 -delete
    continue_on_error: true
  - name: 重启
    action: restart
    target: ${SERVER}
```

简单脚本（一行一条）：

```
@SERVER=survival
backup ${SERVER}
sleep 2
restart ${SERVER}
```

## 第 7 步：改存档（NBT）

「NBT 修改」页 → 选实例 → 自动定位 level.dat → 读取 → 填路径和值 → 写入。
常用路径：`Data.LevelName`（世界名）、`Data.Difficulty`（难度）、`Data.RandomSeed`（种子）。
游戏规则用下面那一栏，选规则填 true/false 即可。每次写都会自动备份 `.bak`。

## 常见报错对照表

| 日志里的提示 | 含义 | 怎么办 |
|---|---|---|
| `You need to agree to the EULA` | 没同意协议 | eula.txt 写 `eula=true` |
| `Could not load plugin` | 插件版本不匹配 | 换对应服务端版本的插件 |
| `Mod resolution failed` | 模组冲突/缺 Fabric API | 装 Fabric API，检查版本 |
| `Java heap space` | 内存不够 | 内存调大（2G → 4G） |
| `Can't keep up!` | 卡顿 | 视距调小、装 Lithium/FerriteCore |
| `Address already in use` | 端口被占 | 换端口或关掉占用程序 |
| `Failed to bind to port` | 端口没权限/被占 | 检查是否 1024 以下端口 |
