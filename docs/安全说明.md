# 安全说明

## 版本选择（避免已知 CVE）

- **Log4Shell（CVE-2021-44228 等）**：下载器默认拉取各核心的**最新稳定版**，这些版本均已修复；启动参数固定带
  `-Dlog4j2.formatMsgNoLookups=true`，作为旧版本的额外缓解。
- **BDS 旧版漏洞**：基岩版服务端一律从官网取最新版本，不使用 1.19.80 及更旧的版本。
- 建议开启「每日维护」流水线自动更新前先备份，更新后看一眼日志分析的结论。

## 面板自身

- 核心只依赖 Python 3 标准库，攻击面小；不含 Flask/Django 等 Web 框架的已知历史问题。
- 文件浏览器所有路径都做越界校验（拒绝 `../`）。
- 面板默认无密码，**仅在局域网使用**；放到公网前请在「设置」设登录密码，并配合 ufw 只放行 8850。
- 密码只存 SHA-256；sudo 密码用 Fernet 加密（密钥 0600），拿不到密钥无法还原。

## 提权

- 优先使用「写入免密 sudoers」，只放行 systemctl / ufw / apt / install / chmod / chown 等必需命令。
- 保存明文 sudo 密码是次选方案；一旦不再需要，用「清除」删掉。

## 服务端运行时

- systemd 单元建议用专用用户（面板 install.sh 会创建 `minecraft` 用户），避免以 root 跑 MC。
- RCON 端口 25575 默认不放行，需要时再开，并设强密码。

## 构建 ISO 时的口令处理（2026-10 修订）

早期版本在 ISO 构建脚本里写死过一个示例 root 口令，属于"把口令写进代码"。
该行已被删除，仓库历史也已重写清除（不再包含任何口令字面量）。

现在的行为：

| 参数 | 行为 |
|---|---|
| 默认 | 每次构建随机生成 20 位口令，仅在构建结束时打印一次，不写进任何文件 |
| `--no-password` | 直接 `passwd -l` 锁定 root，只靠控制台自动登录 + SSH 密钥 |
| `--password <pw>` | 构建者自己指定（**千万别提交进仓库**，建议改用 `--no-password`） |

另外：SSH 默认 `PermitRootLogin prohibit-password` + `PasswordAuthentication no`，
即使设置了口令也无法用于远程登录，避免口令成为攻击面。
